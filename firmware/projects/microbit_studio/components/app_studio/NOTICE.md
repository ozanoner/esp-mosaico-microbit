## The micro:bit name

The footer reads **"works with the BBC micro:bit"**. The Micro:bit Educational
Foundation's brand guidelines permit the micro:bit Word Mark "to state or
indicate that another product is compatible with, works with or can be used with
our products", and prescribe that phrasing. The micro:bit **Logo** is
deliberately not used: the same guidelines forbid using it to indicate
compatibility. The Foundation's name and marks are trademarks of the Micro:bit
Educational Foundation; this project is not affiliated with or endorsed by the
Foundation.
